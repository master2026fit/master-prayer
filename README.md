# 오늘의 기도 PWA v1

개인용 기도 훈련 앱입니다. 광고/회원가입/서버 없이 사용할 수 있습니다.

## 포함 기능
- 매일 바뀌는 오늘의 기도
- 4단계 기도 훈련
- 상황별 기도 8종
- 1분/3분/5분 자유기도 타이머
- 나의 기도 저장
- 기도 완료 달력 및 연속 기도 기록
- JSON 백업/복원
- 오프라인 사용(PWA)

## 설치 방식
이 폴더의 파일을 GitHub Pages 같은 HTTPS 정적 호스팅에 올린 뒤,
갤럭시 Chrome에서 주소를 열고 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.

기도 기록과 나의 기도는 브라우저 localStorage에 저장됩니다.
서버로 자동 전송되지 않습니다.
